### 3. 演習：[SunFounder「2. 初めての回路」](https://docs.sunfounder.com/projects/inventor-lab-kit/ja/latest/lessons/2_first_circuit.html)の回路を Tinkercad で組んで光らせる

**成果物**：5V → 220Ω → LED → GND。LED が点灯した。

![1日目のTinkercad](images/day1-tinkercad.png)

**学んだこと**

**① 回路は1周の輪**

電流は電源の＋から出て、部品を通り、−に戻ってくる。輪がつながっていれば流れ、どこか1か所でも切れると止まる。

閉じた回路（LEDが光る）：

```
5V(+) --> [220Ω] --> [LED] --+
  ^                          |
  +-------- GND(-) <---------+
```

開いた回路（LEDが消える）：

```
5V(+) --> [220Ω] --> [LED] --+
  ^                          x      <- 線が1本抜けている
  +-------- GND(-) <---------+
```

| 言葉 | 意味 | この回路では |
| --- | --- | --- |
| ＋（プラス） | 電流が出ていく側 | Arduinoの **5V** ピン |
| −（マイナス）／GND | 電流が戻ってくる側。電圧の基準（0V） | Arduinoの **GND** ピン |
| 閉じた回路 | 輪がつながっている状態 | LEDが光る |
| 開いた回路 | 輪がどこかで切れている状態 | LEDが消える |

**② ブレッドボードの中のつながり**

穴の中に金属の板が入っていて、同じグループの穴どうしは最初からつながっている。はんだ付けなしで回路が組める。

```
 +  -    a b c d e     f g h i j    +  -
 |  |    o-o-o-o-o     o-o-o-o-o    |  |     <- 1行目：a〜e がつながる / f〜j がつながる
 |  |    o-o-o-o-o     o-o-o-o-o    |  |     <- 2行目：1行目とはつながらない
 |  |            ^     ^            |  |
 |  |            e と f の間（溝）はつながらない
 両端のレール：縦の列全体がつながる（5V と GND を配る）
```

| 場所 | つながり方 | 使い道 |
| --- | --- | --- |
| 中央（a〜e、f〜j） | **横**に5つずつ。行が違えば別 | 部品どうしをつなぐ |
| 両端のレール（＋、−） | **縦**に1列全部 | 5V と GND を配る |

**③ LEDには向きがある**

| 足 | 名前 | つなぐ側 | 回路図の記号 |
| --- | --- | --- | --- |
| 長い方 | アノード | ＋側 | 三角の底の側 |
| 短い方 | カソード | −側 | 三角の先の縦線の側 |

電流はアノード → カソードの一方向にしか流れない。**光らないときは、まずLEDを逆向きに挿し直す。**

**④ 抵抗はLEDを守るために入れる**

抵抗は「電流の流れにくさ」を作る部品。抵抗がないとLEDに電流が流れすぎて壊れる。

- 水道にたとえると、抵抗は**ホースを細くする**ようなもの。細いほど流れる水（電流）が少なくなる。
- 抵抗の値は胴体の色の帯で表す。220Ω は **赤・赤・茶**。（赤・赤・黄だと 220kΩ で、LEDはほとんど光らない）

**⑤ そのほかに覚えておくこと**

| 項目 | 内容 |
| --- | --- |
| ショート | 部品を通さずに 5V と GND を直接つなぐこと。大きな電流が流れて熱くなり、壊れたり火が出たりする |
| 電流の向き | 回路図では＋ → −に流れると考える。実際に動く電子は逆向き（− → ＋） |
| 直流（DC） | 向きが一定。Arduino、電池 |
| 交流（AC） | 向きが周期的に入れ替わる。家のコンセント |
| つなぐ順番 | 電源をつなぐときは＋から、外すときは−から |

## 2日目（火）オームの法則

> **ひとことで**：電圧・電流・抵抗の3つは **V = R × I** の1本の式でつながっている。2つ分かれば残りの1つが計算できる。計算の前に、単位を V・A・Ω にそろえる。

やることの詳細は[チェックリスト](../CHECKLIST.md#第1週-オームの法則直列並列電力)。

### 1. 読む：[抵抗とオームの法則](https://chugaku.manabihiroba.net/rika/ohmhousoku.html)

**学んだこと**

**① 抵抗とは「電流の流れにくさ」**

| 言葉 | 記号 | 単位 | 意味 | 水道にたとえると |
| --- | --- | --- | --- | --- |
| 電圧 | V | V（ボルト） | 電流を押し出す力 | 水を押す水圧 |
| 電流 | I | A（アンペア） | 流れる電気の量 | 流れる水の量 |
| 抵抗 | R | Ω（オーム） | 電流の流れにくさ | ホースの細さ |

抵抗の大きさは、物によって大きく違う。

| 種類 | 抵抗 | 例 | 使い道 |
| --- | --- | --- | --- |
| 導体 | 小さい（よく流れる） | 銅などの金属、炭素 | 導線（銅） |
| 不導体（絶縁体） | とても大きい（ほぼ流れない） | プラスチック、ガラス、ゴム | 導線のカバー |
| 抵抗の大きい金属 | 大きめ | ニクロム | 電熱線（熱を出す） |

**② オームの法則：覚える式は1本だけ**

**V = R × I**（電圧 ＝ 抵抗 × 電流）

この式を入れ替えると、求めたいものに合わせて3つの形になる。

| 求めたいもの | 式 | 使う場面 |
| --- | --- | --- |
| 電圧 V | **V = R × I** | 抵抗と電流が分かっている |
| 電流 I | **I = V ÷ R** | 電圧と抵抗が分かっている（今日の測定） |
| 抵抗 R | **R = V ÷ I** | 電圧と電流が分かっている（3日目の測定） |

覚え方：下の三角で、求めたいものを指で隠すと残りが式になる。上下に並んでいれば「÷」、横に並んでいれば「×」。

```
      +-------+
      |   V   |        V を隠す -> R × I
      +---+---+        I を隠す -> V ÷ R
      | R | I |        R を隠す -> V ÷ I
      +---+---+
```

**③ 計算の前に単位をそろえる**

式に入れるときは、必ず **V・A・Ω** に直してから計算する。

| よく出る単位 | 直し方 | 例 |
| --- | --- | --- |
| mA（ミリアンペア） | ÷ 1000 で A にする | 9mA = 0.009A |
| kΩ（キロオーム） | × 1000 で Ω にする | 1kΩ = 1000Ω |
| MΩ（メガオーム） | × 1,000,000 で Ω にする | 1MΩ = 1,000,000Ω |

**④ 電圧と電流は比例する**

抵抗が同じなら、電圧を2倍にすると電流も2倍になる（I = V ÷ R で、R が一定だから）。

| 電圧（1kΩのとき） | 電流 |
| --- | --- |
| 3V | 3mA |
| 6V | 6mA |
| 9V | 9mA |

1日目に Falstad で見た「電圧を上げると電流の点が速く動く」のは、このこと。

### 2. 解く：同ページの「オームの法則基本」と「計算1」「計算2」の PDF

> **解き方の型**：① 分かっているもの（V・I・R）を書き出す → ② **mA は ÷1000 で A、kΩ は ×1000 で Ω** に直す → ③ 求めたいものの式（V = R × I、I = V ÷ R、R = V ÷ I）に入れる → ④ 聞かれた単位に直す。

| --- | --- |

| ③ 電流が流れないプラスチック・ガラス・ゴムなどを何というか | **不導体（絶縁体）** |

### 3. 検証：Tinkercad で 9V 電池 ＋ 1kΩ を組み、電流モードで測る

**学んだこと**

**① 今日の回路で計算してみる**

回路：9V電池 → 電流計 → 1kΩ → 電池の−

```
9V(+) --> (A) --> [1kΩ] --+
  ^                       |
  +-------- (-) <---------+
```

| 手順 | やること | 計算 |
| --- | --- | --- |
| 1 | 分かっているものを書き出す | V = 9V、R = 1kΩ |
| 2 | 単位をそろえる | R = 1kΩ = 1000Ω |
| 3 | 求めたいもの（電流）の式を選ぶ | I = V ÷ R |
| 4 | 数字を入れる | I = 9 ÷ 1000 = 0.009A |
| 5 | 読みやすい単位に直す | 0.009A = **9mA** |

**② 計算と測定が少しずれる理由：メーターにも抵抗がある**

```
9V --> [電流計の中の抵抗 約1Ω] --> [1kΩ] --> (-)
        |------ 合計 約1001Ω ------|
```

- 電流計の中にも小さな抵抗（内部抵抗）があるので、回路全体の抵抗は 1000Ω ではなく約 1001Ω になる。
- 9V ÷ 1001Ω ≒ 0.00899A = **8.99mA** で、測定と一致する。

## 3日目（水）直列回路

> **ひとことで**：マルチメーターは「何を測るか」でモードとつなぎ方が変わる。抵抗だけは電源を切って測る。LEDのような部品の抵抗は、電圧と電流を測って R = V ÷ I で計算する。

やることの詳細は[チェックリスト](../CHECKLIST.md#第1週-オームの法則直列並列電力)。

### 1. 読む：[直列回路、並列回路の計算](https://chugaku.manabihiroba.net/rika/tyokuretuheiretukeisann.html)の直列部分

**要点**：直列回路は電流の通り道が1本なので、**電流はどこでも同じ**。電源の電圧は各抵抗で**分け合い、足すと電源の電圧**になる。回路全体の抵抗は**各抵抗の足し算**。

### 2. 解く：同ページの PDF 1-1、1-2

> **解き方の型**：まず「直列か並列か」を見る。直列なら電流が全部同じなので、**電流から各抵抗の電圧を出して足す**。並列なら電圧が全部同じなので、**電圧から各枝の電流を出して足す**。最後に「回路全体の抵抗 = 電源の電圧 ÷ 全体の電流」。

**A. 直列回路、並列回路の計算1 NO.1**（[PDF](https://chugaku.manabihiroba.net/wp/wp-content/uploads/2018/06/tyokuretuheiretu1_1.pdf)）

[1] 直列回路

```
+--[20Ω]--[40Ω]--+
|               (A) 0.3A
+-------|I-------+
```

| 問題 | 式 | 答え |
| --- | --- | --- |
| ① 20Ω に流れる電流 | 直列は電流が同じ | **0.3A** |
| ② 40Ω に加わる電圧 | 0.3 × 40 | **12V** |
| ③ 電源の電圧 | 20Ω の電圧 0.3 × 20 = 6V、6 + 12 | **18V** |
| ④ 回路全体の抵抗 | 18 ÷ 0.3（= 20 + 40） | **60Ω** |

> 注意：プリントの解答では ② が「0.3 × 20 = 6V」（20Ω の電圧）になっている。問題は 40Ω の電圧なので、正しくは **12V**。

### 3. 演習：[SunFounder「3. マルチメーターの使い方を学ぶ」](https://docs.sunfounder.com/projects/inventor-lab-kit/ja/latest/lessons/3_multimeter.html)の手順を Tinkercad で再現する

**成果物**

- Tinkercad の回路（1日目の回路にマルチメーターを3台）
  - 電圧（右上、5.00V）：右の＋レールと左の−レール → 回路全体の電圧
  - 電圧（中央、2.02V）：LEDの両足 → LEDにかかる電圧
  - 電流（左、13.5mA）：青い線（a1 → −レール）の代わりに入れて、回路を通る電流
  - 抵抗器（右上の設定欄）：220Ω

  ![3日目のTinkercad](images/day3-tinkercad.png)

**測定値**

| 測ったもの | 値 |
| --- | --- |
| 回路全体の電圧 V | 5.00V |
| LEDにかかる電圧 V_LED | 2.02V |
| 回路を流れる電流 I | 13.5mA = 0.0135A |
| 抵抗器 | 220Ω（Tinkercadの設定値） |

**抵抗の計算**（オームの法則 R = V ÷ I）

| 何を求めるか | 式 | 答え |
| --- | --- | --- |
| ① 回路全体の抵抗 | 5.00V ÷ 0.0135A | 約 **370Ω** |
| ② LEDの分 | ① − 抵抗器 = 370Ω − 220Ω | 約 **150Ω** |
| 答え合わせ：LEDの電圧から | 2.02V ÷ 0.0135A | 約 150Ω（②と一致） |
| 答え合わせ：抵抗器の電圧から | (5.00V − 2.02V) ÷ 0.0135A = 2.98V ÷ 0.0135A | 約 221Ω（設定値の220Ωと一致） |

計算のコツ：電流は **mA を A に直してから**割る（13.5mA = 0.0135A）。

**学んだこと**

**① マルチメーターの3つのモード**

測る前に、まずモードを選ぶ。モードを間違えると「Error」が出たり、回路を壊したりする。

| モード | 測るもの | つなぎ方 | 回路の電源 | たとえ（水道） |
| --- | --- | --- | --- | --- |
| 電圧（V） | 2点の間の電圧 | 部品の両端に**横から当てる**。回路は切らない | 入れたまま | 2か所の水圧の差を見る |
| 電流（A） | 回路を流れる電流 | 回路を1か所切り、すき間に**メーターをはさむ** | 入れたまま | 管の途中に流量計をはさむ |
| 抵抗（R） | 部品の抵抗値 | 部品だけを取り出して両端に当てる | **切る** | 水を止めてから管の細さを調べる |

**② 電圧計と電流計のつなぎ方の違い**

電圧計（V）：回路は切らずに、測りたい部品の両端に当てる。

```
5V --> [220Ω] --+--> [LED] --+--> GND
                |            |
                +----(V)-----+      <- LEDの両端の電圧を見る
```

電流計（A）：回路を1か所切って、すき間にメーターをはさむ。

```
5V --> [220Ω] --> [LED] --x  x--> GND     <- x の所で線を切る
                          |  |
                          +(A)+           <- 電流がメーターの中を通る
```

- 電流は回路を1周して流れるので、**メーターの中を通らないと測れない**。
- 直列回路（1本道の回路）では、電流はどこでも同じ。だから、どこを切ってメーターを入れても同じ 13.5mA になる。

**③ 抵抗モードは電源を切って使う**

抵抗モードのメーターは、次の手順で抵抗を出している。

1. メーター**自身の電池**から、決まった小さな電流を部品に流す
2. そのとき部品の両端に出た電圧を測る
3. R = V ÷ I で抵抗を計算する

回路の電源が入っていると、Arduinoからの電流も混ざって計算が狂う。だから「Error」になる。**実物のマルチメーターでも同じ**で、抵抗は電源を切ってから、できれば部品を回路から外して測る。

> たとえ：誰かが上から手で押している体重計に乗っても、正しい体重は出ない。手（電源）をどけてから測る。

**④ LEDの抵抗は計算で出す**

LEDは、約2V かからないと電流をほとんど流さない。抵抗モードのメーターが流す電圧は低いので、LEDに当てても正しい値が出ない。そこで、光っている状態で電圧と電流を測り、オームの法則で計算する。

| 分かっていること | 求めるもの | 式 |
| --- | --- | --- |
| 電圧 V と電流 I | 抵抗 R | **R = V ÷ I** |

LEDの「抵抗」は、流れる電流によって変わる。今回の 150Ω は「13.5mA 流れているときだけの値」で、抵抗器の 220Ω のように決まった値ではない。

**⑤ 直列回路では、電圧を部品で分け合う**

```
5.00V --> [220Ω] --> [LED] --> GND
           2.98V      2.02V
          |-- 合計 5.00V --|
```

電源の 5.00V を、抵抗器が 2.98V、LEDが 2.02V と分け合っている。足すと電源の電圧に戻る。

**⑥ 抵抗器がないと電流が増えすぎる（失敗から分かったこと）**

電源が入ったまま、抵抗モードのメーターを抵抗器の両端に当てたら、メーターが抵抗器の「迂回路」になった。

| | 電流 | LEDの電圧 | LED |
| --- | --- | --- | --- |
| ふつう（抵抗器が効いている） | 13.5mA | 2.02V | 光る |
| 迂回した（抵抗器が効いていない） | **319mA**（約24倍） | 4.00V | **壊れた** |

抵抗器が電流を抑えてLEDを守っていたことが、目で見て分かった。

### 4. 記録：SunFounder の測定例と自分の値を並べ、違いの理由を1行

| | 電圧 | 電流 | 回路全体の抵抗 | 抵抗器 | LEDの分 |
| --- | --- | --- | --- | --- | --- |
| SunFounder（実物） | 5.13V | 13.54mA | 5.13 ÷ 0.01354 ≒ 379Ω | 215Ω（実測） | 379 − 215 ≒ 164Ω |
| Tinkercad | 5.00V | 13.5mA | 5.00 ÷ 0.0135 ≒ 370Ω | 220Ω（設定値） | 370 − 220 = 150Ω |

## 4日目（木）並列回路と合成抵抗

> **ひとことで**：抵抗を大きくすると電流が減ってLEDは暗くなる。直列は「1本道」で電流が同じ・電圧を分け合う。並列は「枝分かれ」で電圧が同じ・電流を分け合う。

やることの詳細は[チェックリスト](../CHECKLIST.md#第1週-オームの法則直列並列電力)。

### 1. 読む：[回路全体の抵抗](https://chugaku.manabihiroba.net/rika/kairoteiko.html)と[MONOist 電子工作“超”入門(4) キルヒホッフの法則](https://monoist.itmedia.co.jp/mn/articles/1501/26/news020.html)の合成抵抗の部分

**学んだこと**

**① 合成抵抗：いくつかの抵抗を1本にまとめた値**

| つなぎ方 | 式 | 1Ω を2本つないだとき | 覚え方 |
| --- | --- | --- | --- |
| 直列 | R = R1 + R2 | 1 + 1 = **2Ω**（大きくなる） | 道が長くなる |
| 並列 | R = (R1 × R2) ÷ (R1 + R2) | (1 × 1) ÷ (1 + 1) = **0.5Ω**（小さくなる） | 道が増えて流れやすくなる |

同じ抵抗を2本並列にすると、ちょうど半分になる。

**② キルヒホッフの法則（読んだだけ。詳しくはあとで）**

直列と並列が混ざり、電池が2つ以上ある回路は、合成抵抗だけでは解けない。そこで次の2つのきまりを使う。

| 法則 | 内容 | 今日の測定で言うと |
| --- | --- | --- |
| 第1法則（電流） | 1つの点に入る電流の合計 ＝ 出る電流の合計 | 並列で、合計 27.1mA が 13.5mA ずつに分かれる |
| 第2法則（電圧） | 回路を1周すると、電圧の上がり下がりの合計は 0 | 直列で、5V = 1.15 + 1.93 + 1.93 |

> 注意：MONOist の例題（Ea＝3V、Eb＝1.5V、Ra〜Rd＝1Ω）の答え「Ia＝2A、Ib＝1A」は誤り。記事の式をそのまま解くと Ia＝1A、Ib＝1A、I＝2A になり、式自体も回路図と合っていない。回路図どおりに正しく解くと、Ra に 3A、Rd に 0A、Rb‖Rc に 3A が流れる。

**確認問題**：「回路全体の抵抗」のページについている練習プリントで確かめた。

> **解き方の型**：回路全体の抵抗は「**電源の電圧 ÷ 全体の電流**」。電源の電圧か全体の電流が書いていないときは、直列・並列のきまりで先にそれを出す。抵抗が2つとも分かっていれば、合成抵抗の式（直列 R1 + R2、並列 (R1 × R2) ÷ (R1 + R2)）でも出せる。

| ⑦ | 直列 | 全体 650mA、抵抗が 8V と 5V | 電源 13V、13 ÷ 0.65 | **20Ω** |
| ⑧ | 並列 | 上の枝 1.2A、下の枝 30Ω で 0.8A | 電源 0.8 × 30 = 24V、全体 2A、24 ÷ 2 | **12Ω** |

> 引っかけに注意：③ の「9V」や「10V」は片方の抵抗の電圧で、全体の抵抗には使わない。**全体の抵抗には、必ず電源の電圧と全体の電流を使う。**

**成果物**

**測定値**

| 電源 | 抵抗 | 電流 | LEDの電圧（電源 − 電流 × 抵抗） | LEDの見た目 |
| --- | --- | --- | --- | --- |
| 5V | 100Ω | 28.6mA | 5 − 2.86 = 2.14V | とても明るい（「!」の警告） |
| 5V | 220Ω | 13.5mA | 5 − 2.97 = 2.03V | ふつう |
| 5V | 1kΩ | 3.11mA | 5 − 3.11 = 1.89V | 暗め |
| 5V | 10kΩ | 323µA（0.323mA） | 5 − 3.23 = 1.77V | かなり暗い |
| 5V | 1MΩ | 0.00A（数µA で表示されない） | — | 消えている |
| 3.3V | 220Ω | 6.18mA | 3.3 − 1.36 = 1.94V | 5V より暗い |

**学んだこと**

**① 抵抗を大きくすると、電流が減ってLEDが暗くなる**

```
100Ω   28.6mA   ##########  とても明るい
220Ω   13.5mA   #####       ふつう
1kΩ    3.11mA   #           暗い
10kΩ   0.32mA   .           かなり暗い
1MΩ    約0      (消える)
```

- 抵抗を10倍にすると、電流はだいたい10分の1になる（1kΩ → 10kΩ で 3.11mA → 0.32mA）。
- 電源を 5V → 3.3V に下げても、電流が減って暗くなる（220Ω で 13.5mA → 6.18mA）。

**② LEDが使う電圧は、電流が変わってもほぼ 2V のまま**

上の表のとおり、電流が約90倍変わっても、LEDの電圧は 1.8〜2.1V の間にとどまる。だから電流は次の式でおおよそ予想できる。

| 予想の式 | 例（5V、220Ω） |
| --- | --- |
| **電流 ≒ (電源 − 約2V) ÷ 抵抗** | (5 − 2) ÷ 220 ≒ 13.6mA（測定 13.5mA） |

**③ LEDに流してよい電流には上限がある**

| | 電流 |
| --- | --- |
| ふつうの赤LEDの目安 | 約 20mA まで |
| 100Ω のとき | 28.6mA → 超えている（Tinkercad が「!」で警告） |

実物だと熱くなって寿命が縮む。**5V で赤LEDを使うときは 220Ω** を使うのはこのため。

**測定値**

| --- | --- | --- | --- | --- | --- |

C. 並列回路

| 1列目の電圧 | 2列目の電圧 | 1列目の電流 | 2列目の電流 | 合計の電流 |
| --- | --- | --- | --- | --- |
| 5.00V | 5.00V | 13.5mA | 13.5mA | **27.1mA** |

**学んだこと**

**① 直列と並列のちがい**

直列：1本道

```
5V --> [LED1] --> [LED2] --> [抵抗] --> GND
```

並列：枝分かれ

```
5V --+--> [LED1] --> [抵抗] --+--> GND
     |                        |
     +--> [LED2] --> [抵抗] --+
```

| | 直列 | 並列 |
| --- | --- | --- |
| 電流の通り道 | 1本だけ | 枝ごとに別々 |
| 電流 | **どこでも同じ**（5.22mA と 5.22mA） | **枝ごとに分かれ、合計は足し算**（13.5 + 13.5 = 27.1mA） |
| 電圧 | **部品で分け合う**（1.15 + 1.93 + 1.93 = 5V） | **どの枝も電源と同じ**（5.00V と 5.00V） |
| LEDの明るさ | 暗い（電圧を分け合うので電流が減る） | 1個のときと同じ |
| 電源から出る電流 | 少ない（5.22mA） | 多い（27.1mA。LEDを増やすほど増える） |
| 1個こわれると | **全部消える** | **残りは光る** |
| 身近な例 | 1本道の線路 | 部屋ごとのコンセント |

**② メーターのつなぎ方の失敗から分かったこと**

| 失敗 | 何が起きたか | 正しくは |
| --- | --- | --- |
| 電流計を LED の**両足に並べて**当てた | 電流計（ほぼ 0Ω）が LED の迂回路になり、LED が消えた。電流は「電源 ÷ 抵抗」のLEDなしの値（220Ω で 22.7mA）になった | 線を1本外し、すき間に**はさむ** |
| **電圧計**を回路のすき間にはさんだ | 電圧計（とても大きい抵抗）で回路が切れたのと同じになり、LED が消えた | 電流を測るときはモードを **A** にする |
| **A モード**のメーターを＋と−のレールに当てたままにした | 5V と GND を直接つないだ**ショート**になり、25.0kA と表示された | 使わないメーターは消すか V モードにする |

測る前に、**すべてのメーターのモード（A・V・R）とつなぎ方**を確かめる。

| モード | つなぎ方 | メーターの中の抵抗 |
| --- | --- | --- |
| 電圧（V） | 部品の両端に**横から当てる** | とても大きい（電流をほぼ通さない） |
| 電流（A） | 回路を切って**すき間にはさむ** | ほぼ 0Ω（電流をそのまま通す） |

### 4. 記録：「直列で1個壊れると全部消え、並列だと残りが光る」理由を2行

> 直列は電流の通り道が1本だけなので、1か所でも切れると道が全部ふさがり、すべてのLEDが消える。
> 並列はLEDごとに電源につながる別々の道があるので、1本が切れても他の道はそのまま使え、残りのLEDは光り続ける。
