## 元記事の目標

回路図を読み、動く回路を作り、動かないときに原因を見つけられるようになること。

元記事はこの月を一番大事な土台としています。ロボットの不具合は、ゆるんだ線、弱った電池、レギュレータ（電圧を一定にする部品）が出せる以上の電流をモーターが引いた、といった電気の問題であることが多く、電気の層を知らないと原因が分からないからです。

## このフェーズで使う道具

すべて無料です。

- [Tinkercad Circuits](https://www.tinkercad.com/circuits)：仮想のブレッドボードとテスター
- [Falstad CircuitJS](https://www.falstad.com/circuit/)：電流の流れをアニメーションで見る
- [KiCad](https://www.kicad.org/)：回路図を描く
- [中学学習プリント「電流・電圧と回路」](https://chugaku.manabihiroba.net/rikaindex/1bunyarika)：計算ドリル（フェーズ2以降も週3回続ける）
