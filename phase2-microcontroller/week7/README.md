## 46日目 IMU（加速度とジャイロ）の基礎

**やること**（詳細は [チェックリスト](../CHECKLIST.md#第7週-センサーとフィルタ)）

- 読む：SunFounder「加速度センサー & ジャイロスコープモジュール（MPU6050）」
- 読む：おもろ家「Arduino 入門 番外編 06【I2C通信 とは】」
- 調べる：Wokwiの部品説明から、MPU6050のI2Cアドレス（0x68、AD0ピンをVCCにつなぐと0x69）と、SDA・SCLのピンを自分で見つけてメモする

- 改造：加速度のYとZから、`atan2()` で傾き角（ピッチ）を出してシリアルに表示する
