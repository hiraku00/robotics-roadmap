## 元記事の目標

動いて、周りを感じ取って、自分で修正するロボットを作ること。

元記事は、ライントレースロボットを「センサーの入力、モーターの出力、調整の問題がそろった制御ループ（測る → 判断する → 動かす、の繰り返し）で、人型ロボットと同じものを小さく安く壊せるようにしたもの」と説明しています。このリポジトリでは実機の代わりに、Tinkercad・Wokwi・Python のシミュレーションで同じ考え方を練習します。

## 到達目標（元記事の Month 2 Milestone）

55日目に確かめます。

## 元記事との主な違い

- ESP32 で Web ページを配信する課題は、Wokwi では有料の機能が必要なので実機待ちにしました（51日目）。
- 倒立振子ロボット（2輪で立つロボット）は、フィルタと制御の両方が要るので、制御を詳しくやるフェーズ5で Python のシミュレーションとして作ります。
- スマートサーボ（位置を返すサーボ）は、使い道のロボットアームと一緒にフェーズ3で扱います。
